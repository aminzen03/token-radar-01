Token Radar ranks pre-token DeFi protocols by the implied value a token launch would be worth, from a sealed DefiLlama snapshot, and shows each protocol's farm plan in a static dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```

Then open `out/dashboard/index.html` in a browser.
